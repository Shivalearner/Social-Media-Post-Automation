# Social Media Post Automation

A full-stack social media management platform for creating, generating, scheduling, and publishing content across multiple social media platforms from a single dashboard.

## 🚀 Features

* JWT-based user authentication
* Connect and manage social media accounts
* OAuth integration for supported platforms
* AI-powered post generation
* Create and schedule social media posts
* Publish posts through Zernio API
* Media upload with Cloudinary
* Dashboard with posts, accounts, and activity
* Automated background publishing with Node Cron

## 🛠️ Tech Stack

**Frontend**

* React 19
* TypeScript
* Vite
* Tailwind CSS
* React Router
* Axios

**Backend**

* Node.js
* Express.js
* TypeScript
* MongoDB & Mongoose
* JWT & bcrypt
* Google Gemini API
* Zernio API
* Cloudinary
* Node Cron
